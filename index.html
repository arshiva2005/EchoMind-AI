Add your Groq API key

EchoMind AI uses the Groq API to generate your reflections. Your key is stored only in your browser (localStorage) and sent directly to Groq with each request — it never touches our logs.

Get a free key at console.groq.com/keys (sign in, click "Create Key", copy it here). Leave empty to use the server key if one is configured.
